# ㄱㅇㅈ PWA v1.0

동해 낚시 초보자를 위한 설치형 웹앱(PWA)입니다.

## 포함 기능
- 오늘 낚시 점수 및 초보 추천
- 간조·만조, 물때, 바다 상태 예시 화면
- 낮/밤 예상 어종
- 어종별 초보 채비
- 동해안 포인트
- 왕초보 낚시교실
- 낚시 기록 로컬 저장
- 홈 화면 설치 및 오프라인 캐시

## 중요
현재 기상, 수온, 물때, 추천 점수는 **데모 데이터**입니다.
실시간 서비스 전에는 공식 API 연동과 안전·금어기 정보 검증이 필요합니다.

## GitHub Pages 배포
1. 이 폴더 안의 파일을 저장소 최상위에 업로드합니다.
2. 저장소의 Settings → Pages로 이동합니다.
3. Build and deployment에서 `Deploy from a branch`를 선택합니다.
4. Branch는 `main`, 폴더는 `/(root)`로 선택하고 Save를 누릅니다.
5. 잠시 뒤 제공되는 주소로 접속합니다.

아이폰에서는 Safari 공유 버튼 → `홈 화면에 추가`로 설치할 수 있습니다.
